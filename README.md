## Features
- **Portfolio Hero** with greeting, role, and resume/contact actions.
- **About Me** card and compact skill grid.
- **Experience & Education** timeline sections.
- **Project cards** with live demo and GitHub links.
- **Responsive layout** for desktop and mobile.

## Run Locally
### Prerequisites
- Node.js + npm

### Start Frontend
```bash
git clone https://github.com/kathanpatel29/PortfolioWeb.git
cd PortfolioWeb/frontend
npm install
npm run dev
```
Open `http://localhost:5173` in your browser.

## Project Structure
- `frontend/` → React + Vite portfolio UI
  - `src/components` → UI sections
  - `src/data` → content data and labels
  - `src/assets` → images and icons

## About This Portfolio
This project is a personal portfolio website for showcasing your experience, education, technical skills, and projects in a modern style. It includes:
